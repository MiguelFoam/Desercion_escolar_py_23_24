# Proyecto de Monitoreo de Emisiones de CO₂

Este repositorio contiene el desarrollo y documentación técnica del proyecto de análisis de emisiones de dióxido de carbono (CO₂), enfocado en métricas clave para evaluar el impacto ambiental y proponer soluciones basadas en datos.

## Objetivo

Diseñar un sistema de seguimiento y análisis de emisiones de CO₂ que permita visualizar tendencias, identificar fuentes críticas y apoyar decisiones estratégicas en sostenibilidad.

## Métricas Analizadas

- **Métrica 1**: Indicador principal de emisiones por sector o fuente.
- **Métrica 2**: Comparativa temporal de emisiones (mensual, anual).
- **Métrica 3**: Proyección de reducción bajo distintos escenarios de intervención.

## Tecnologías Utilizadas

- Pentaho para limpieza y validación de datos.
- PostgreSQL para almacenamiento y consultas de datos.
- PoweBI para la visualización de datos.

## 🔍 Metodología
1. Limpieza de datos (valores faltantes, codificación).
2. Exploración de variables socioeconómicas y regionales.
3. Visualización de tendencias de deserción.
4. Interpretación de resultados.
